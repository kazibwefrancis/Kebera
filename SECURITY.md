# Security

## Reporting a problem in Kebera

If you find a way Kebera could leak private information, change settings, or be
misused, please **don't open a public issue**. Use GitHub's private
"Report a vulnerability" option on this repository (Security tab), or contact the
maintainer privately.

## Vulnerabilities in routers or provider equipment

Kebera is not a security scanner, and this project doesn't collect or publish
vulnerabilities in routers, outdoor units or provider systems. If you believe a
device or provider service is vulnerable, report it to the manufacturer or provider
through their responsible-disclosure channel.
